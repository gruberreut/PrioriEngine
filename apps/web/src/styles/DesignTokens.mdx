# Design Tokens

All component colors, spacing, and border-radius values must reference tokens defined in `src/styles/tokens.css` — never a raw hex or pixel value in component CSS. For the color palette itself — swatches, contrast ratios, dark mode, and the rationale behind it — see [Color Story](./ColorStory.mdx). This page covers everything else the token contract includes: spacing, border radius, and font families below.

> **Font families are tokenized** (`--font-sans`, `--font-heading`, `--font-mono`). **Font sizes and font weights are not.** Use plain size/weight values directly in each component's `.module.css` file.
