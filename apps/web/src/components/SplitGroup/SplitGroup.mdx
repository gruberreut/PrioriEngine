# SplitGroup

A joined, mutually-exclusive segmented control — 2 or more options in one bordered track, seams between segments, selected segment filled with the accent tint. Distinct from `Chip`'s separate, "pick any" pills. See `documentation/DESIGN-TOKENS-BY-COMPONENT.md` § 4.4 for the design rationale.

Every `--split-*` custom property declared in `tokens.css`, resolved live — follows the theme toolbar above.
