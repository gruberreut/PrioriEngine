# TextInput

One label/control/help triplet, shared between `TextInput` (single-line) and `Textarea` (multiline) — not three separate components. An `error` message replaces `help` and swaps the border/help color; it never changes the field's background. See `documentation/DESIGN-TOKENS-BY-COMPONENT.md` § 4.2 for the design rationale.
