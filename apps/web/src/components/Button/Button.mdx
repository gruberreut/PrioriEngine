# Button

Four variants (`primary` filled, `secondary`/`ghost`/`destructive` outlined) and three sizes (`sm` 36px, `md` 46px, `icon` 44px square). Primary is always a fill — this app never mixes a TempAppName fill with a Nocturne outline. See `documentation/DESIGN-TOKENS-BY-COMPONENT.md` § 4.1 for the design rationale.
