# Chip

A 34px pill toggle button with an optional leading `icon`. Selection state (`selected`) and exclusivity (single- vs. multi-select) are the composing component's job — `Chip` itself is a single controlled toggle, same division of responsibility as `Radio`/`Checkbox`. Selected swaps to a `--color-primary-tint` fill with `--color-primary` text and a transparent border. See `documentation/DESIGN-TOKENS-BY-COMPONENT.md` § 4.4 for the design rationale.
