# ListRow

A selectable list item: `title` with an optional `meta` line below it, in a 44px-minimum bordered row. Every row has an 8px leading dot; `selected` swaps the border/background to the accent tint and recolors the dot to match (muted otherwise). See `documentation/DESIGN-TOKENS-BY-COMPONENT.md` § 4.4 for the design rationale.

Scoped to rows that are genuinely "pick one from a list" (e.g. `TaskCreationPage`'s parent-task picker) — a disclosure/expand row like `TaskTreeItem`'s isn't the same shape (no selection state, a leading chevron instead of a dot, trailing content instead of a meta line) and isn't built on this primitive.
